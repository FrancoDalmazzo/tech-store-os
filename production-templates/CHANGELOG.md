# Changelog

Todos los cambios relevantes de Tech Store OS se documentan en este archivo.

## [1.3.0] — 2026-08-16

### Agregado

- Biblioteca con diez plantillas de producción para Instagram y WhatsApp.
- Editor de etiqueta, título, producto, texto de apoyo, precio, financiación y CTA.
- Carga local de fotografías reales.
- Vista previa adaptable para formatos 9:16 y 4:5.
- Exportación PNG en resolución nativa 1080×1920 o 1080×1350.
- Controles editoriales contra precios, stock, financiación, urgencia y testimonios inventados.
- Manual de uso, checklist de publicación e instrucciones de ejecución local.

### Identidad

- Paleta de trabajo: Tech Blue `#3C7AC3`, Tech Dark `#252527` y White `#FFFFFF`.
- Voz cercana argentina con uso de “vos”.
