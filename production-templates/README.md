# Tech Store OS — Production Templates v1.3

Herramienta de producción visual reutilizable para Tech Store B&B. Permite editar, previsualizar y descargar piezas PNG listas para redes, sin depender de una cuenta o servicio externo.

## Incluye

1. Instagram Story Master — 1080×1920
2. Producto — 1080×1350
3. Promoción — 1080×1350
4. Carrusel educativo — 1080×1350
5. Portada de Reel — 1080×1920
6. WhatsApp Status — 1080×1920
7. Precio / financiación — 1080×1350
8. Nuevo ingreso / unboxing — 1080×1920
9. Canje de equipos — 1080×1350
10. Local / equipo — 1080×1350

## Uso local

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run dev
```

Abrí la dirección local indicada, elegí una plantilla, completá únicamente datos confirmados, incorporá una foto real y descargá el PNG.

## Identidad

- Tech Blue: `#3C7AC3`
- Tech Dark: `#252527`
- White: `#FFFFFF`
- Voz: cercana, clara, argentina y con “vos”.

La guía completa está en [docs/USO.md](docs/USO.md). La evolución del proyecto está registrada en [CHANGELOG.md](CHANGELOG.md).

## Seguridad editorial

Los campos comerciales comienzan vacíos. La herramienta nunca genera precios, stock, cuotas, vencimientos, urgencia ni testimonios. La persona que publica debe verificar cada dato contra la fuente interna vigente.
